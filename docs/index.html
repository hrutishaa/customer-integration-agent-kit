Customer Integration Agent Kit live demo

Sample customer Acme Outdoor Co.: sync contacts from a flaky mock CRM REST API and a CSV export into one schema. A declarative mapping renames, casts, fills defaults and computes fields; a bad row is reported and skipped. Retries, a dry-run diff and idempotent upserts run in your browser, no keys.
